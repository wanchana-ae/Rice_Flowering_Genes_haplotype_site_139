# Rice_Flowering_Genes_haplotype_site_139

Preliminary (draft 2026-11-06, not validated): haplotype analyses of flowering-time genes in **139 photosensitive (P) accessions only** (∆DTF>35 d, no Hd1 deletion) — the 146-accession analysis without the 7 NP accessions that have no Hd1 deletion. Sections 1–5 use ∆DTF, sections 6–8 the flowering date in short day (SD) and long day (LD), section 9 is the GWAS (Manhattan/QQ plots), section 10 compares SD and LD per gene on one y-axis. No accession names/IDs. There is no P/NP covariate (no NP set).

- `index.html` — results page
- `figures/`, `img/` — figures
- `data/` — downloadable tables (csv, xlsx)

Visual style: paper theme adapted from the design ideas and colour tokens of [Looseleaf](https://github.com/kevintngo/looseleaf) by Kevin Ngo (MIT licence); CSS only, no code or fonts copied.
